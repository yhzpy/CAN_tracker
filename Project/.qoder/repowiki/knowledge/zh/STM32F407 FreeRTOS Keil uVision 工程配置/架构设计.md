本模块不包含业务源码，而是 Keil uVision IDE 的工程元数据：
- `f407_freeRTOS.uvprojx` 是核心项目文件，声明 TargetName=`F407_freeRTOS`、Device=`STM32F407ZG`、Cpu=`Cortex-M4`、Toolset=`ARM-ADS`（V5.06 update 7），输出二进制名为 `Charge`。
- 源文件按逻辑分组组织在 Groups 中：Driver/CMSIS（启动与系统初始化）、Driver/FWLIB（ST 标准外设库）、Driver/SYSTEM（delay/sys/usart 基础驱动）、Driver/BSP（LED/OLED/SDIO_CAN/RTC/RS485/power_mgmt 板级驱动）、Driver/LCD、Middle/malloc、Middle/FreeRTOS_core（croutine/event_groups/list/queue/stream_buffer/tasks/timers）、Middle/FreeRTOS_port（heap_4.c + ARM_CM4F port.c）、Middle/FATFS、User（main/app/BMS279/ymodem_protocol/FreeRTOSConfig.h）。
- IncludePath 指向 `..\Driver\CMSIS`、`..\Driver\FWLIB\inc`、`..\Middle\FreeRTOS\portable\RVDS\ARM_CM4F` 等目录，Define 包含 `STM32F40_41xxx,USE_STDPERIPH_DRIVER`。
- 链接器 TextAddressRange=0x08000000、DataAddressRange=0x20000000，OnChipMemories 定义 IROM(0x08000000,0x100000)、IRAM(0x20000000,0x20000)、IRAM2(0x10000000,0x10000)。
- `DebugConfig/*.dbgconf` 为各目标对应的调试器初始化脚本，统一设置 DBGMCU_CR=0x00000007（保留 sleep/stop/standby 调试位），APB1/APB2_FZ 冻结寄存器保持复位值；文件名后缀对应不同芯片型号（STM32F407ZG / STM32F407ZGTx）。
- `f407_freeRTOS.uvoptx` 与 `f407_freeRTOS.uvguix.*` 是 Keil 工作区/用户界面状态文件，记录打开的文件列表、窗口布局及用户名（Administrator/智能设备）。
- `_delay_new.c.tmp` 是编译器生成的临时延迟函数实现，非持久源码。
